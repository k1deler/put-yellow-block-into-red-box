# 黄色物块 → 红色盒子

面向I2RT YAM双臂机器人的单任务训练与执行项目。任务标识为`put_block_in_bowl`；包括模型登记、独立环境安装、离线验证、起始姿态对齐、动作调度和每轮运行记录。

## 当前配置

| 项目 | 设置 |
|---|---|
| 任务 | 将黄色物块放入红色盒子 |
| 模型格式 | `yam_train/act_ref-v1` |
| 动作表示 | 14维增量目标，按同一次观测状态还原 |
| 观测 | 双腕RGB相机480×640，从臂14维状态 |
| 动作块 | 100步、30Hz；每60步重规划、0.1秒交叉淡化 |
| 单轮上限 | 40秒；完成后由操作员结束 |
| 控制 | 100Hz、worker看门狗与驱动保护 |

真实权重在实验室主机本地指定并登记，不随仓库提交。安装、训练和执行使用独立目录，保留已跑通版本用于回退。

## 安装和使用

在独立目录克隆本仓库，然后指定实际的可信模型绝对路径：

```bash
bash setup_yellow_red.sh /absolute/path/to/block_bowl_delta.pt
```

也可用环境变量`TASK_CHECKPOINT`指定路径。安装器创建独立Python环境，补齐并校验公开机械资源，核对任务和格式，运行测试及GPU离线检查，不启动真实设备。步骤见[安装与操作](先看这里.md)。

自检通过后，在有现场监护的交互终端运行：

```bash
bash start_local.sh
```

支持交互SSH。输入`START`后会初始化驱动并移动至模型保存的起始姿态，到位后再按Enter开始任务。

| 输入 | 行为 |
|---|---|
| Enter | 开始／暂停／继续，暂停时通电保持 |
| `r`＋Enter | 结束本轮并移动回起始姿态 |
| `q`＋Enter | 正常归位后关闭电机 |

`q`和Ctrl+C会触发归位运动，不是立即原地急停；异常运动使用现场物理急停。SSH断开不代表安全停止。不要同时运行多套设备控制程序。
