## 部署原则

先在实验室主机独立目录安装及无硬件验证，原可运行目录保留。真实权重由安装器在主机本地复制，未经格式、任务、自检校验不会生成放行凭证。请以实际日志为准，仓库中的历史通过报告不能作为另一台主机的放行证据。

启动会初始化驱动并移动至示范起始姿态；运行时 Enter 开始／暂停，`r`＋回车结束一轮并回位，`q`＋回车归位退出。`q`和Ctrl+C会触发归位运动，不能替代物理急停。

仓库不存储SSH/GitHub密码、访问令牌、模型权重、原始数据、相机视频和本机依赖。`.gitignore`明确排除这些内容；之后提交前仍需检查暂存区。
